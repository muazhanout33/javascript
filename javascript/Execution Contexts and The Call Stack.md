🍕 تخيل إن JavaScript مطعم بيتزا

عندنا 3 حاجات مهمة:

👨‍🍳 الشيف (JavaScript Engine)
📦 صندوق (Execution Context)
🗂️ طابور صناديق (Call Stack)
📦 أول فكرة: إيه اللي بيحصل لما الكود يشتغل؟

أول ما تفتح الموقع:

👉 JavaScript بتعمل صندوق كبير اسمه Global Box

ده زي:

“غرفة اللعب الأساسية”

وفيه أي كود مش جوه دالة

🧠 مثال بسيط:
let a = 5;

function add() {
  return 2 + 3;
}
هنا بيحصل إيه؟
a = 5 → بيتحط في الصندوق الكبير
add() → بيتسجل بس (مش بيتنفذ)
🍕 دلوقتي الدوال (Functions)

تخيل كل function = صندوق صغير خاص بيها

لكن الصندوق ده:
👉 مش بيتفتح غير لما تنادي عليه

📞 لما تنادي function
add();

بيحصل الآتي:

👉 JavaScript تعمل صندوق جديد صغير
👉 تحط فيه add()
👉 وتحطه فوق الصندوق الكبير

🗂️ Call Stack (طابور الصناديق)

تخيل عندك طاولة:

بتحط الصناديق فوق بعض
آخر صندوق يتحط هو اللي بيتفتح الأول

ده اسمه:

Stack = رصّ فوق بعض

🧱 مثال خطوة خطوة
function first() {
  second();
}

function second() {
  console.log("Hi");
}

first();
👇 كده بيحصل بالراحة:
1️⃣ البداية
فيه صندوق كبير اسمه Global
2️⃣ first() تتنادى
يتعمل صندوق اسمه first
يتحط فوق Global
[first]
[Global]
3️⃣ first تنادي second
يتعمل صندوق جديد second
يتحط فوق first
[second] ← شغال دلوقتي
[first]
[Global]
4️⃣ second تخلص
الصندوق يتشال
[first]
[Global]
5️⃣ first تخلص
يتشال
[Global]
🧠 أهم فكرة هنا:

👉 JavaScript تشتغل "واحدة واحدة"
مش بتعمل حاجتين في نفس الوقت

📦 جوه كل صندوق (Execution Context)

كل صندوق فيه 3 حاجات بسيطة:

1. 🧾 متغيرات

زي:

let x = 10;
2. 📞 arguments

لو function واخدة مدخلات

3. 🧭 معلوماتها هي تشتغل إزاي
🧠 مثال طفولي جدًا:

تخيل function زي طفل في غرفة:

عنده لعبه (متغيرات)
عنده تعليمات (الكود)
ومسموح له يشتغل لما يناديه حد
🔥 حاجة مهمة جدًا:
لما function تنادي function تانية:

⛔ الأولى بتقف شوية
👶 وتستنى الصغيرة تخلص

🍕 التشبيه النهائي:
Global = مطبخ المطعم
Function = صندوق بيتزا
Call Stack = رصّ الصناديق فوق بعض
Execution Context = صندوق فيه كل أدوات الأكل
🎯 الخلاصة كأنك طفل:
JavaScript بتعمل صناديق للكود
كل function لها صندوق خاص
الصناديق بتترص فوق بعض
اللي فوق هو اللي شغال
لما يخلص يتشال ونرجع اللي تحته

لو عايز، أقدر أشرح لك بعد كده:
👉 
event loop
👉 
callback queue
👉 أو 
أديك لعبة بسيطة تتخيل بيها call stack بنفسك
